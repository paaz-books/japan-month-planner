# Japan Month Planner

Score 11 regions of Japan for every month by what matters to you: weather, crowds, cost, things to see and risk. A companion to paaz's guide to a first trip to Japan.

- Planner: https://paaz-books.github.io/japan-month-planner/
- `index.html`: the whole planner in one file (data as of September 30, 2026)
